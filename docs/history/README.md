# Historical documents

These are Sun Tech's internal design notes, written in Italian while the WCS was being built and
extracted from Kazam. They describe the system as it was on the date of each one and are kept for
reference only: they are not kept up to date, and where they disagree with the code or with the
current documentation, the code and the [current documentation](../README.md) win. Each sits under
this folder at the path it has in Sun Tech's internal repository, less its doc/ folder. Their links
to lines of code have become plain text: the lines have moved since.
